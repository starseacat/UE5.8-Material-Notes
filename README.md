# UE5.8-Material-Notes
（一）方形渐变：生成一个"中心亮、四周暗"的方形渐变遮罩，用来做方形光斑/边框/渐变。
<img width="1261" height="562" alt="image" src="https://github.com/user-attachments/assets/1dc4f26c-9e5b-4aa9-8f75-e5466cdbcf0d" />
一、逐节点官方解释＋大白话
1. TexCoord[0]（Texture Coordinate／纹理坐标）
官方定义：输出 UV 纹理坐标（双通道向量），可指定使用第几套 UV 通道、U/V 方向的平铺数量，以及镜像开关。
大白话：告诉材质"贴图上的点在哪儿"——U 是横向、V 是纵向，范围都是 0～1。
本图设置：坐标索引 0（第一套 UV），平铺 1×1。
2. Mask (R)（Component Mask／组件蒙版）
官方定义：从输入向量中选取一个通道子集输出（可勾选 R/G/B/A）。
大白话：UV 是"两个数"，这个节点只把横向的 U 单独拎出来。
设置：只勾 R。
3. Mask (G)（Component Mask／组件蒙版）
官方定义：同上，选取通道子集输出。
大白话：只把纵向的 V 单独拎出来。
设置：只勾 G。
4. Constant 0.5（常量）
官方定义：输出一个单精度浮点常量值。
大白话：一个固定的数 0.5，用来把 UV 从"左下角原点"平移到"中心原点"。
5. Subtract（减法）
官方定义：两个输入相减，输出 A − B。
大白话：U 减 0.5（V 也减 0.5），让原点从角落挪到正中心。
6. Abs（绝对值）
官方定义：输出输入的绝对值（无符号值）。
大白话：负数翻正——中心左右、上下两边完全对称，不会一边黑一边白。
7. Constant 2.0（常量）
官方定义：输出一个单精度浮点常量值。
大白话：|U−0.5| 的范围只有 0～0.5，乘 2 拉回 0～1，方便后面反相。
8. Multiply（乘法）
官方定义：两个输入逐通道相乘，输出 A × B。
大白话：把"到中心的距离"放大两倍，铺满整个 0～1 区间。
9. OneMinus（1-x）
官方定义：把 0～1 的输入反相，输出 1 − 输入。
大白话：翻转黑白——中心原来是 0（黑），翻转后变 1（白）；边缘原来是 1，翻转后变 0（黑）。这样才是"中心亮、四周暗"。
10. Min（最小值）
官方定义：比较两个输入，输出较小的那个。
大白话：U 方向和 V 方向的两条渐变"取小的那个"——两个方向同时衰减，等值线就变成方形（菱形）轮廓。

二、连接顺序与目的
第一步，TexCoord 同时接到两个 Mask 上——目的是把 UV 拆成 U 和 V 两条独立的线，因为方形渐变要对两个轴分别做同样的处理，最后再合并。

第二步，Mask(R) 接到第一个 Subtract 的 A，Constant 0.5 接到它的 B——目的是 U−0.5，把横向坐标的原点从左边挪到正中心；Mask(G) 那条线同样接一套，把 V−0.5，纵向原点也挪到中心。

第三步，两个 Subtract 的输出分别接 Abs——目的是取绝对值，让中心向左和向右、向上和向下的数值完全对称，避免负值导致半边发黑。

第四步，两个 Abs 的输出分别接 Multiply 的 A，同一个 Constant 2.0 接到两个 Multiply 的 B——目的是把 0～0.5 的数值范围重新拉伸回 0～1，为后面的反相做准备。

第五步，两个 Multiply 的输出分别接 OneMinus——目的是反相：把"中心0、边缘1"翻成"中心1、边缘0"，得到中心亮的灰度。

第六步，U 分支和 V 分支做完后分别接 Min 的 A 和 B——目的是取两轴中较小的值，让"横向衰减"和"纵向衰减"同时成立，轮廓就变成方形的渐变。

第七步，Min 的输出接基础颜色（或自发光颜色）——目的是把 0～1 的灰度直接当颜色显示，预览里就是那个中心白、四边黑的方形光斑。

材质域是 Post Process，所以这里 UV 是屏幕坐标、渐变会铺满全屏；如果把它改成 Surface 材质贴在平面上，UV 就变成模型 UV，效果相同，只是"贴在哪"不同。

三、快捷键与搜索方式

Mask (R) / Mask (G)：无快捷键，搜索 ComponentMask，类别 向量操作（Vector Ops）

Constant 0.5：快捷键 1（按住 1 再左键点击）

Constant 2.0：快捷键 1

Subtract：快捷键 S（部分版本区分，不生效就搜 Subtract，类别 数学 Math）

Abs：无快捷键，搜索 Abs，类别 数学（Math）

Multiply：快捷键 M

OneMinus（1-x）：快捷键 O（不生效就搜 OneMinus，类别 数学 Math）

Min：无快捷键，搜索 Min，类别 数学（Math）

一句话总结：方形渐变＝拆UV→各自减0.5→取绝对值→×2→反相→取小合并；核心是"两个轴分别算，最后取最小值"。

（二）中心渐变：生成圆形径向渐变：中心亮、四周暗（光晕/暗角/聚焦遮罩）。
<img width="1262" height="557" alt="image" src="https://github.com/user-attachments/assets/a984a5a8-8a5e-4857-9b7e-f7c06818747e" />

一、逐节点官方解释＋大白话
1. TexCoord[0]（纹理坐标）
官方定义：输出 UV 纹理坐标（双通道向量），可指定 UV 通道、U/V 平铺和镜像开关。
大白话：提供每个像素的位置——U 横向、V 纵向，0～1。
如果没有它：Distance 就没有"像素坐标"可输入，等于只拿到一个固定值，整张图变成纯色，渐变完全消失。

2. Constant2Vector (0.5, 0.5)（二维向量常量）【新节点】
官方定义：输出双通道向量常量（X、Y 两个数）。
大白话：一个固定坐标点 (0.5,0.5)——正好是屏幕正中心。
如果没有它：Distance 没有"B 点"可比较，默认会按 (0,0) 计算——光斑会跑到左下角，中心渐变变"角落渐变"。

3. Distance（距离）【新节点】
官方定义：计算两个点/颜色/位置/向量之间的欧几里得距离，两个输入通道数必须一致；伪代码 `Result = length(A − B)`。
大白话：算"每个像素离屏幕中心有多远"——中心0、边缘0.5、角落约0.707。
如果没有它：拿不到"离中心多远"这个数据；只能用绝对值/点积去凑，结果会变成方形光斑（那就是①的方形渐变），出不来圆形。

4. Multiply（乘法）＋ Constant 2.0（常量）
官方定义：Multiply 输出 A × B（逐通道）；Constant 输出一个浮点常量。
大白话：把"距离"放大两倍。
如果没有它：距离最大只有 0.707，反相后边缘不会完全归零，光斑边缘会发灰、范围太大，一直糊到画面角落，不够聚拢。

5. Saturate（饱和）【新节点】
官方定义：把输入值钳制到 0～1 区间。
大白话：超过1的按1算、低于0的按0算——"卡死范围"。
如果没有它：距离×2 后最大到 1.414，OneMinus 会算出 1−1.414＝−0.414 这种负值——过渡会不自然，可能出现硬边或颜色异常。

6. OneMinus（1-x）
官方定义：把 0～1 的输入反相，输出 1 − 输入。
大白话：翻转黑白——中心距离0变1（白），边缘距离大变小（黑）。
如果没有它：输出是"中心黑、边缘白"——光斑变成黑洞，方向完全反了。

二、连接顺序与目的

第一步，TexCoord 接到 Distance 的 A，Constant2Vector(0.5,0.5) 接到 Distance 的 B——目的是让"每个像素的位置"和"屏幕中心点"相减，算出每个像素到中心的直线距离，中心得0、边缘约0.5、角落约0.707。

第二步，Distance 的输出接 Multiply 的 A，Constant 2.0 接 Multiply 的 B——目的是把距离放大两倍，让衰减更紧凑，光斑正好在屏幕边缘收干净。

第三步，Multiply 接 Saturate——目的是把超过1的数值截断到1，保证后面反相不会出现负值，边缘过渡干净。

第四步，Saturate 接 OneMinus——目的是反相：中心从0变1（亮），边缘从1变0（暗），得到"中心亮、四周暗"的圆形渐变。

第五步，OneMinus 接自发光颜色——目的是把渐变作为自发光输出；因为截图里材质域是 Post Process，它会全屏叠加，相当于给屏幕中心加一圈光晕/暗角。若改成 Surface 材质贴在平面上，UV 变成模型 UV，效果相同。

三、快捷键与搜索方式

Constant2Vector：快捷键2（按住 2 再左键点击）
Distance：无快捷键，搜索Distance，官方分类为工具（Utility Material Expressions）
Saturate：无快捷键，搜索Saturate，类别数学（Math）

一句话总结：中心渐变＝UV与中心点算距离→×2收紧→Saturate限幅→1−x反相；核心是"用距离代替坐标轴"，所以轮廓是圆的。

（三）StaticSwitch＋StaticBool 二选一：用布尔值在两套颜色/材质方案之间切换，常用于材质变体、画质档位、平台适配。

一、逐节点官方解释＋大白话
1. Constant3Vector（1,0,0）——作用：输出固定红色
官方定义：输出三通道向量常量（X、Y、Z 三个固定数），可直接当颜色使用。
大白话：写死的红色。

2. Constant3Vector（0,1,0）——作用：输出固定绿色
官方定义：输出三通道向量常量。
大白话：写死的绿色。

3. StaticBool（True）——作用：提供静态布尔值
官方定义：提供编译期确定的布尔值，供静态开关使用；修改会触发着色器重新编译。
大白话：一个打勾的硬开关，现在是 True。

4. StaticSwitch（面板显示 Switch）——作用：按布尔值二选一
官方定义：根据 Value 输入的布尔值，在 True 和 False 两个输入间选择并输出。
大白话：True 走上面、False 走下面。

二、连接顺序与目的
第一步，红色常量接 StaticSwitch 的 True，绿色常量接 False——准备两套颜色方案。

第二步，StaticBool（True）接 StaticSwitch 的 Value——给开关明确的判断值，当前为 True，走 True 分支。

第三步，StaticSwitch 输出接自发光颜色——把选中的颜色作为发光输出，当前预览为红色。

第四步，取消 StaticBool 勾选——开关改走 False，输出绿色；此操作触发材质重新编译，属于配置级切换。

（四）If 三路选择：比较 A、B 两个数值，按大于、等于、小于三种结果各选一路输出，常用于三档状态或方案切换
<img width="1280" height="597" alt="image" src="https://github.com/user-attachments/assets/16062bf5-9cdf-4060-924e-99f2545c2024" />
一、逐节点官方解释＋大白话
1. Constant3Vector（1,0,0）——作用：输出红色，接“A＞B”分支
官方定义：输出三通道向量常量（X、Y、Z 三个固定数），可直接当颜色使用。
大白话：预设的红色，代表“A 大于 B”时的结果。

2. Constant3Vector（0,1,0）——作用：输出绿色，接“A＝B”分支
官方定义：输出三通道向量常量。
大白话：预设的绿色，代表“A 等于 B”时的结果。

3. Constant3Vector（0,0,1）——作用：输出蓝色，接“A＜B”分支
官方定义：输出三通道向量常量。
大白话：预设的蓝色，代表“A 小于 B”时的结果。

4. Constant（0.0）×2——作用：提供 A、B 两个比较值
官方定义：输出一个单精度浮点常量。
大白话：两个都设为 0 的数，交给 If 去比较大小。

5. If——作用：按 A、B 的比较结果选一路输出
官方定义：比较 A 和 B 两个输入，若 A＞B 输出“A＞B”分支、若 A＝B 输出“A＝B”分支、若 A＜B 输出“A＜B”分支；属性“等于阈值（Equals Threshold）”默认 0.00001，用于浮点数近似相等判断。
大白话：比大小，三路里选一路。

二、连接顺序与目的
第一步，红色常量接 If 的 A＞B、绿色接 A＝B、蓝色接 A＜B——目的是给三种比较结果各准备一套颜色。

第二步，两个 Constant（0.0）分别接 If 的 A 和 B——目的是提供比较值；当前 A＝B＝0，所以走“等于”分支。

第三步，If 输出接自发光颜色——目的是把选中的颜色作为发光输出；当前预览为绿色。

第四步，改数值验证：把 B 改成 1（A＜B）→ 输出蓝色；把 A 改成 1（A＞B）→ 输出红色；只有 A、B 相等时才是绿色。

三、快捷键与搜索方式
If
无快捷键，搜索 If，类别数学（Math）
作用：比较 A、B 两个输入，按大于、等于、小于输出对应分支
广义用途：三档状态切换（低、中、高档；干燥、湿润、积水；白天、黄昏、夜晚）、分级遮罩、A、B、C 方案选择
注意：与 StaticSwitch 的区别是——StaticSwitch 按布尔二选一，If 按数值比较三选一

一句话总结：If 比较 A、B，大于、等于、小于各接一路，谁成立就输出谁；当前 A＝B＝0，所以输出绿色。


（五）Cross 叉积：求同时垂直于两个向量的方向，常用于构建坐标系、计算面法线与旋转轴
<img width="1273" height="560" alt="image" src="https://github.com/user-attachments/assets/3490bf0a-dc61-44bc-b339-45fc426ce55f" />
一、逐节点官方解释＋大白话
1. Constant3Vector（1,0,0）——作用：输出向量 A（红色）
官方定义：输出三通道向量常量（X、Y、Z 三个固定数）。
大白话：红色＝(1,0,0)，可以理解为 X 轴方向。

2. Constant3Vector（0,1,0）——作用：输出向量 B（绿色）
官方定义：输出三通道向量常量。
大白话：绿色＝(0,1,0)，可以理解为 Y 轴方向。

3. Cross——作用：计算两个三维向量的叉积
官方定义：CrossProduct 表达式计算两个三通道向量的叉积，输出一个同时垂直于两个输入的向量；结果长度等于 |A||B|sinθ，方向符合右手定则，且与输入顺序有关（A×B＝−B×A）。
大白话：红×绿＝蓝——结果垂直于两者，正好是 Z 轴。

二、连接顺序与目的
第一步，红色常量接 Cross 的 A，绿色常量接 B——给叉积提供两个输入向量，也就是 X 轴和 Y 轴。

第二步，Cross 输出接自发光颜色——叉积结果是 (0,0,1)，所以预览整屏为蓝色；这也验证了“结果垂直于两个输入”。

第三步，交换 A、B 的位置——结果变成 (0,0,−1)，负值在颜色里会按 0 处理（变黑）；说明叉积有方向性，A×B 与 B×A 正好相反，需要正数时可先接 Abs。

三、快捷键与搜索方式
Cross
无快捷键，搜索 Cross（或 CrossProduct），类别数学（Math）
作用：计算两个三维向量的叉积，输出同时垂直于两者的向量
广义用途：构建局部坐标系（切线、副切线、法线）、求面法线与旋转轴、程序化几何与方向类计算
注意：结果有方向性，A×B 与 B×A 相反；长度＝|A||B|sinθ

一句话总结：Cross 求两个向量的垂直方向——红(X)×绿(Y)＝蓝(Z)；顺序反过来，结果方向也反过来。

（六）Normalize 归一化：把向量长度变为1、方向不变，常用于方向、法线与点积计算前的标准化
<img width="1280" height="562" alt="image" src="https://github.com/user-attachments/assets/9075ffd1-6dae-4832-bfe8-735d805532e9" />
一、逐节点官方解释＋大白话
1. Constant3Vector（12,0,0）——作用：输出一个长度为12的红色向量
官方定义：输出三通道向量常量（X、Y、Z 三个固定数）。
大白话：方向朝红（X轴），但长度是12，不是单位长度。

2. Normalize——作用：把任意向量变成单位向量
官方定义：输出与输入同方向的单位向量（长度1）；如果输入是零向量，输出为零。
大白话：方向不变，长度变1——(12,0,0) 进去，(1,0,0) 出来。

二、连接顺序与目的
第一步，将 Constant3Vector（12,0,0）接到 Normalize 的 VectorInput，给归一化一个“超长”的输入向量，方便观察长度被压缩。

第二步，将 Normalize 输出接到自发光颜色，把结果可视化；输出为 (1,0,0)，所以预览是纯红。如果直接接原始常量（12,0,0），颜色通道会把超过 1 的数值截断，看起来同样是满红，但数值含义不同：一个长度是 12，一个是 1。

第三步，理解用途：归一化只改长度、不改方向，因此凡是“只关心方向、不关心长度”的计算，都必须先归一化，例如点积求夹角、法线计算、光照方向、速度方向。

三、快捷键与搜索方式
Normalize
无快捷键，搜索 Normalize，类别数学（Math）
作用：输出同方向的单位向量（长度1）
广义用途：法线、方向向量标准化、点积与夹角计算前的准备、光照与视线方向、程序化方向控制
注意：零向量不能归一化（返回零），注意避免除零

一句话总结：Normalize 只保留方向、长度变1——(12,0,0) 变 (1,0,0)；方向类计算前先归一化。

第二步，三组 UV 分别接三个 TextureSample，Texture Object 负责提供图片——目的是得到三张不同方向的投影图像。

第三步，VertexNormalWS 接 Abs，再拆 X、Y、Z——目的是把法线三个方向变成三个0～1的权重；再用 Add 求和、Normalize 归一化，确保三个权重加起来为1。

第四步，用两次 Lerp 按权重混合三个投影：先混第一、第二，再和第三混——目的是在三个方向的交界处自然过渡，不出现硬接缝。

第五步，混合结果接基础颜色——目的是把三个方向的投影合成一张完整表面。

官方定义：输出输入的正弦值（输入为弧度，周期 2π）。
大白话：时间往前走，它就在 −1 和 1 之间来回摆，形成“去—回”的节奏。

3. Constant（25）——作用：控制往返的幅度
官方定义：输出一个单精度浮点常量。
大白话：最大挪动 25 个单位（UE 里 1 单位＝1 厘米）。

4. Multiply（第一个）——作用：波形×幅度
官方定义：两个输入逐通道相乘，输出 A × B。
大白话：把 −1～1 的波放大成 −25～25 的位移量。

5. Constant3Vector（1,0,0）——作用：指定移动方向
官方定义：输出三通道向量常量（X、Y、Z 三个固定数）。
大白话：(1,0,0) 就是沿 X 轴（红色方向）移动。

6. Multiply（第二个）——作用：位移量×方向＝三维位移向量
官方定义：两个输入逐通道相乘，输出 A × B。
大白话：把“走多远”变成“往哪个方向走多远”的完整三维数据。

官方定义：材质输出引脚，用于在世界空间中偏移顶点位置。
大白话：前面算的是数据，接到这里模型才会真的动。

二、连接顺序与目的
第一步，Time 接 Sine——目的是把一直增大的时间压成 −1～1 的循环波，形成往返节奏。

第二步，Sine 接第一个 Multiply 的 A，Constant 25 接 B——目的是把波幅放大到 ±25，决定运动距离。

第三步，第一个 Multiply 接第二个 Multiply 的 A，Constant3Vector(1,0,0) 接 B——目的是给位移一个明确方向：沿 X 轴。

第四步，第二个 Multiply 接全局位置偏移——目的是让顶点沿 X 轴做 ±25 的往返运动；材质域是 Surface，所以是物体自身在动。静态截图看不出运动，进入关卡实时预览才能看到。

第五步，变体调整：改方向常量就能沿 Y、Z 或斜向移动；改 25 控制幅度；把 Sine 换成 Cosine 可以改变起始位置；在 Time 后乘速度再进 Sine 可以控制快慢。

一句话总结：Time喂给Sine得到往返波，乘25定幅度、乘方向向量定路线，接到全局位置偏移，物体就会沿指定方向来回移动。

17. 强度参数（ScalarParameter，默认1.00318）——作用：控制飘动幅度
官方定义：标量参数，可在实例中覆盖。
大白话：数值越大，布面起伏越明显。

18. Multiply（×强度）——作用：位移量×强度
官方定义：逐通道相乘A×B。
大白话：把波幅放大到合适的厘米数。

19. 全局位置偏移（World Position Offset）——作用：让顶点真正移动
官方定义：材质输出引脚，在世界空间偏移顶点位置。
大白话：前面算的是数据，接到这才真的飘。

20. 基础颜色——作用：输出旗面颜色
官方定义：材质基础色输入。
大白话：Logo与条纹叠加后的最终颜色。

二、连接顺序与目的
第一步，TexCoord经两个Mask拆出U、V，V乘0.5后与U相加，再乘形状参数（2）——目的是把普通UV拧成一个“斜向且可控密度”的坐标。

第二步，Time乘速度参数（1）后加到上面的坐标上，再进Sine——目的是让这个斜向坐标随时间平移，产生流动的周期波。

第三步，Sine的输出分成两路：一路乘红色常量，得到斜向条纹颜色；另一路留给顶点位移用——同一个波，两种用途。

第四步，TextureSample用整理过的UV（TexCoord→Mask→Append→Multiply→Saturate）采样Logo贴图，然后与条纹颜色叠加，接基础颜色——旗面既有Logo又有流动纹理。

第五步，Sine乘VertexNormalWS，再乘强度参数（1.00318），接全局位置偏移——目的是让每个顶点沿法线按同一个波起伏，布面就飘起来了。

第六步，三个参数（形状2、速度1、强度1.00318）做成材质实例后即可分别调密度、快慢、幅度——一套逻辑多套旗帜。

三、快捷键与搜索方式
ScalarParameter（标量参数）
无快捷键，搜索 ScalarParameter，类别参数（Parameters）
作用：提供可在材质实例中覆盖的单个数值
广义用途：亮度、强度、速度、密度、粗糙度、自发光——所有需要“外部可调”的数值
注意：命名要见名知意并设置分组（如“旗帜控制”）；材质实例里必须勾 Override 才生效

一句话总结：一个Sine波分两路——×颜色进基础颜色，×法线进全局位置偏移；形状、速度、强度三个标量参数一调，旗帜的密度、快慢、幅度全都能变。

（十六·增补）旗帜材质进阶：多贴图与多层波形叠加，让旗面颜色和飘动更接近真实
比上一版多出来的部分主要分四类：
一、新增模块逐项说明
1. 第二张颜色/纹理贴图（左侧新增的彩色节点）

作用：给旗面叠加颜色变化或布料纹理；
为什么更真实：上一版是“纯色＋条纹”，像程序生成的塑料布；加一层贴图后，布面有色差、明暗不均和细节，接近真实织物的观感。
广义用途：布纹、脏旧、渐变底色、图案叠加都靠这一层。
2. 新增的 UV 缩放/采样链（TexCoord→Mask→Multiply→Saturate→TextureSample 的 UVs）

作用：控制图案的平铺比例和采样范围；
为什么更真实：图案比例对了，Logo 不会被拉伸、纹理密度和布料尺寸匹配。
新增的“缩放参数”就是给这条链用的。
3. 第二组 Sine/ Add/ Multiply（中部的两层波形结构）

作用：在主条纹之外再叠一层不同频率或方向的波；
为什么更真实：单一频率的条纹太规律，像机器印的；两层波叠加后出现不规则起伏，接近布料自然的褶皱和纹理变化。
这是“更像真布”的最大来源之一。
4. 位移链的多级乘法（VertexNormalWS×强度，再叠一层）

作用：把两层波都作用到顶点位移上，或分两级控制幅度；
为什么更真实：褶皱有大小层次——大起伏带小起伏，不是整块布同步鼓包。
广义用途：布料、水面、旗帜、悬挂物都靠“多层波叠加”做自然感。
二、修改的部分
原来的单链 Sine 变成双链：一条管主条纹，一条管细节/褶皱；
参数变多：新增缩放参数，速度/强度可能也拆成了两组——控制粒度更细；
颜色输出路径变了：贴图与条纹先混合再进基础颜色，不再是简单的“贴图＋条纹”；
位移路径变长：多了一次乘法，幅度受两个参数影响。
三、为什么这一版更真实（三条原理）
颜色不再单一：贴图提供自然的色差和细节；
图案不再规律：两层不同频率的波叠加，打破机械感；
位移有层次：大波带小波，褶皱像被风吹出来的，而不是均匀鼓包。
四、性能与取舍
每多一张贴图就多一次采样、多一份显存——当前旗帜效果值得；
如果以后要优化：优先砍“第二层波”的采样次数，保留颜色贴图和主波；
参数越多，材质实例越容易调——但命名要清楚，建议分组为“旗帜-颜色 / 旗帜-动画 / 旗帜-位移”。
五、给笔记的结论
上一版解决“会动、会飘”；这一版解决“像真的”：贴图给细节、双层波给自然、参数给控制。

一句话总结：多加的不是多余节点，而是三层真实感——颜色细节（贴图）、纹理不规则（双波叠加）、褶皱层次（多级位移）；控制好参数，这就是一面像样的旗。

（补充）合并节点：原理、形状与选型
一、一句话总纲
这五个节点干的都是同一件事——把横、竖两条"亮带"合起来；区别只在于离开中心时数值掉得多快、以什么方式掉。形状不是画出来的，是数值衰减规律“长”出来的。

二、五个节点的本质（带数字锚点）
Min：跟随掉得快的那条。
中心 min(1,1)=1；横走 0.25 得 0.5，斜走 0.25 还是 0.5——横着走和斜着走一样亮，等亮线是横平竖直的，所以是方形。它只认“掉得多的那一条”，另一条是 1 也补不上。

Multiply：平方级衰减。
中心 1×1=1；横走 0.25 得 0.5；斜走 0.25 时两条同时掉，0.5×0.5=0.25，再斜到 0.2×0.2=0.04。两边一起掉、还相乘，掉得最猛，四角塌得最快，所以是圆形柔光，过渡最软。

Add：先冲顶、再截断。
中心 1+1=2，被截成 1；横走 0.25 是 0.5+1=1.5，还是截成 1；一直白到边缘。只有两边同时掉到 0.5 以下才低于 1，所以白区撑到斜线边界，是菱形白饼，中心是一块死白不是渐变。

Max：横竖不掉。
中心 1；横走 0.25 是 max(0.5,1)=1，横走 0.4 还是 max(0.2,1)=1——只要站在中心线上，总有一条恒 1，所以亮线一路顶到边。只有斜着同时离开两条线才掉，所以是十字／四角星。它“取大不取和”，永远不会叠到 2，所以不会过曝。

Subtract：有方向的差。
中心 1−1=0；往上走 1−0.5=0.5、1−0.2=0.8，一路涨到 1（亮）；往右走 0.5−1=−0.5、0−1=−1，负数被截成 0（全黑）；对角线两边相等、恒为 0（黑线）。所以只有上下两块亮楔形，分界是 45° 对角线，是竖沙漏。它是唯一天生出负值、只能亮一半的节点。

三、柔和度排序（从软到硬）
Multiply（最软，平方衰减）→ Min（线性）→ Max（线性，但亮区拉成长线）→ Add／Subtract（最硬，边界是截断造出来的）

这条排序就是“什么时候不能用哪个”的答案：想要雾、光晕这种糊的东西，别用 Add；想要清楚边缘的图案，别用 Multiply。

四、什么时候用哪个
Multiply：柔光、光晕、衰减遮罩、距离雾；两张遮罩“同时满足”取交集；颜色相乘做染色／压暗；AO、阴影强度的调制；把边缘光柔和地叠到基础色上。

Add：多层发光／多光源叠加（先各乘 0.5 降亮度防爆）；两张遮罩亮度相加取并集；几个小遮罩拼成一个大遮罩；噪声、细节层叠加；自发光累加。

Max：十字光、四角星、硬边形状；遮罩取并集但不希望叠亮（任一条满足即可，用来替代 Add 防过曝）；两组遮罩任一出现就显示（比如边缘和划痕任一都算）；取“最亮”的合成，如两层高光取大。

Min：方形／矩形、硬边交集（两者都满足）；多层遮罩取“共同覆盖区”；给数值封顶（当简易 Clamp 用）；取“最暗”的合成，如多层阴影叠加取最小。

Subtract：斜切遮罩、对角渐变（直接 U−V 最快）；挖洞／镂空（A 有 B 无）；差值检测（两张图不一样的地方）；方向性遮罩（左右／上下渐变、月牙、缺口）；从整体遮罩里扣掉某块区域。

五、选型三问（三十秒定节点）
需不需要方向、正负、一半黑？ 需要 → Subtract，别的都做不到。
是“两者都满足”还是“任一满足”？ 都满足 → 交集族；任一满足 → 并集族。
边界要软还是要硬？ 软 → Multiply；硬 → Min；并集里要“发光叠亮” → Add，只要形状不要过曝 → Max。
对应到把方形渐变最后一步换节点：

觉得方形太硬、想要圆形柔光 → Multiply
想要十字光／四角星 → Max
想要大块纯白/更强遮罩 → Add
想要斜切、一半黑、沙漏 → Subtract
想要沙漏两边都亮（对称） → Subtract 之后加 Abs
六、易错点
Add 必过曝：1+1=2 被截成 1，中心出现死白平台——先乘 0.5 或改用 Max；
Subtract 的负半边是纯黑不是暗灰：负数被截成 0，想要对称先 Abs；
Multiply 显得太暗：平方衰减，同参数下光斑比 Min 小，需提亮；
Max 不是“相加”：它取大的，不会把两层亮度累加，所以做叠加发光时别拿它当 Add 用；
全部逐通道运算：RGB 分别算，颜色和单通道遮罩别混接，否则会偏色。
一句话总结：形状＝数值离开中心时的衰减方式——Min 匀速（方）、Multiply 平方（圆）、Add 冲顶（菱形白饼）、Max 不掉（十字）、Subtract 一半正一半负（沙漏）；选节点先问三件事：要不要方向、交集还是并集、边界要软还是要硬。

（二）中心渐变

中心渐变，使用distance时，连接了二维常量，是否可看作将圆心也就是最白的移到了中心还是什么（无法精准描述出疑问，但不妨碍AI给出解读）

AI回答：

给定一个坐标点当圆心，算图像上每个像素到它的距离：距离为 0 的点最白，距离越大越黑。

链路：Distance（求距离）→ ×2（定半径）→ Saturate（把超过 1 的压平）→ OneMinus（0 变白、1 变黑）。

一句话：Distance 算“离圆心多远”，OneMinus 把它翻译成“越远越黑”。

我的理解：给定一个点，再站在图像的角度，图像上某点跟给定的这个点的之间的距离越大，（经1-x反相后）画面越暗，反之则越亮

注意：Distance 本身是距离越大、数值越大、画面越亮，这里是加了OneMinus

（三）二选一

这个没有疑问，下面是AI的拓展，先记一下

拓展一：母材质变体管理（最常用）
场景：同一类资产要出多种状态——金属／非金属、有无细节法线、灯亮／灯灭、屏幕内容 A/B。

做法：母材质里用 StaticBool 当总开关，True／False 各接一套颜色或贴图；每个 Material Instance 勾不同的 Override，就得到不同变体，但只维护一份材质图。

好处：逻辑只改母材质一处，所有实例跟着变，不用复制十几个材质。
注意：MI 里改 StaticBool 也会触发该变体重编译。

拓展二：性能分档（高配／低配）
场景：同一套资产要兼顾 PC 高画质和移动端或低端机。

做法：StaticSwitch 的 False 分支接“简化版”（少一次采样、少一层混合），低配 MI 关掉高成本分支。

原理：StaticSwitch 是编译期选择，没选中的分支根本不进 shader——比运行时 Lerp 把两条分支都算一遍省得多。
注意：每多一个 StaticBool，shader 变体数翻倍（2 的 n 次方），工程上一般控制在 3～4 个以内。

拓展三：平台／功能适配
同一材质在 PC 和移动端需要不同实现（比如高端平台开视差、移动端关掉），用静态开关分编译，而不是运行时判断——这是“一套资产多平台”的常规做法。

反向拓展：什么时候不能用它
需要运行时切换的：开关灯动画、天气变化、血量／能量条、角色受伤闪白——这些用普通 Scalar／Vector 参数＋Lerp，用 StaticSwitch 每次切换都重编译，会卡顿；

判断条件来自运行时数据（时间、距离、玩家状态）：接不进 StaticBool，它只吃静态值；

和第四课 If 的分工：

StaticSwitch＝编译期二选一，只保留一条分支；
If＝运行时比较，两条分支都编译。
判断标准就一句：这个条件在运行时会不会变。会变 → If／Lerp；不会变 → StaticSwitch。

工程注意
StaticSwitch 的 Value 只能接 StaticBool 或常量，接 Time／普通参数会报错；
变体数量＝2 的 n 次方，n 是 StaticBool 个数，直接决定编译时间和包体；
改勾会重编译——这是迭代速度问题，不是运行时开关（已知坑，工程上要算进时间）。
一句话总结：StaticSwitch 是“编译期的二选一”——拿来做变体管理和性能分档最划算；凡是运行时才决定的事，一律交给参数＋Lerp／If。

（四）IF三路选择

没有疑问，下面是AI的拓展

拓展一：贴图二值化／硬边遮罩（最常用）
接法：A＝贴图灰度（或 Alpha），B＝阈值参数（常用 0.5）；
效果：A > B 走白、A < B 走黑——任何灰度图立刻变成纯黑白硬边遮罩；
例：树叶镂空（Opacity Mask：灰度 0.7 > 0.5 保留，0.3 < 0.5 透明）、图案 stencil、卡通描边底图、磨损区域硬切；
对比：想要软边不用 If，用 SmoothStep 或 Lerp——If 是刀切，SmoothStep 是渐变。

拓展二：运行时开关（和 StaticSwitch 分工）
接法：A＝ScalarParameter（0 或 1），B＝0.5 → 大于走 True 路、小于走 False 路；
用途：灯亮／灯灭、角色受伤闪白、UI 选中态、特效开关——能被蓝图或 Sequencer 动画驱动；
代价：If 是运行时判断，两条分支都参与编译；GPU 上甚至可能两边都算（谓词化执行），别指望它省性能；
口诀：不会变 → StaticSwitch；会变 → If／Lerp。

拓展三：状态分档与分层
高度分层：A＝世界坐标 Z，B＝海平面 0 → 高于输出岩石色、低于输出水色；
距离分层：A＝像素到相机的距离，B＝阈值 → 近处／远处两套表现（距离淡出、LOD 视觉简化）；
三态灯：A＝状态参数，B＝1：>1 绿灯、<1 红灯、==1 黄灯；
提醒：浮点数几乎不可能精确等于，判断“相等”要改成 Abs(A−B) < 0.001 再进 If，别依赖默认容差 0.00001。
拓展四：调试可视化
把某个参数（粗糙度、法线强度、UV 密度）接 A、阈值接 B，超过就染红——做材质排查时一眼看出哪里超标，比肉眼看灰度快得多。

反向拓展：什么时候别用 If
要软过渡 → SmoothStep／Lerp；
条件编译期就定死 → StaticSwitch，省变体也省指令；
只是单阈值硬切 → Step 更轻，少一路判断；
If 的“==”那路默认容差 0.00001，实际项目里基本只能当兜底用。
一句话总结：If 是“运行时的三岔路口”——适合阈值化、运行开关、分层分档；要省性能用 StaticSwitch，要软边用 SmoothStep，要判断相等先 Abs 再比。

（五）cross叉积

无疑问，以下是AI拓展

拓展一：构建正交坐标系（最核心）
已知两个方向，叉出第三个互相垂直的轴——TBN 矩阵就是这么来的。

例：粒子／广告牌永远面向相机——已知相机朝向 F 和世界上方向 U，Cross(F, U) 得到右方向 R，再用一次 Cross 补全上方向，就得到一组正交基，把四边形对齐到相机。
同类用途：程序化切线、贴花投影方向、任意轴旋转的基向量。

拓展二：求平面法线
已知平面上两个不共线的方向，叉积就是该平面的法线。

例：由 UV 的 du／dv 切向叉出表面法线（程序化法线）；三角面由两条边叉出法线判断正反面；地形由两个坡度方向叉出坡面朝向。
注意：法线朝哪边由 A×B 的顺序决定，接反了法线直接翻面。

拓展三：贴表面的流动方向（场景里最常用）
Cross(风方向, 表面法线) → 得到一个贴着表面、垂直于风向的方向；再叉一次就得到“顺着表面往下流”的方向。

用途：雨滴沿斜面流下、雪在坡面堆积的方向、旗帜贴面飘动——所有“顺着表面走”的效果都靠它。

拓展四：2D 旋转 90° ／ 环形图案
Cross(V, (0,0,1)) 相当于把 V 在平面内转 90°。

用途：UV 旋转（比 Rotator 更可控）、径向／环形图案的切向、把任意方向掰成垂直方向做条纹。

拓展五：判断左右／朝向
Cross(A,B) 的符号（2D 里看 Z 分量）能判断 B 在 A 的左边还是右边；配合 Dot 还能判断目标在不在扇形视野内。
用途：角色／怪物朝向判断、UI 指针方向、视野检测。

工程注意
A×B = −B×A：顺序反了方向就反，法线翻面、旋转倒转；
|A×B| = |A||B|sinθ：输入不是单位向量时结果会被放大，接颜色或方向前先 Normalize；
两向量平行时叉积为零向量，后面接 Normalize 会出问题（你笔记里那条零向量坑）；
结果永远垂直于两个输入——所以它天生是“造轴、造方向”的节点，不是“调颜色”的节点；
和 Dot 配合：Dot 判平行／垂直，Cross 求垂直方向；dot(cross(A,B), C) 的符号还能判左右。

一句话总结：叉积就是把“两个方向”变成“第三个垂直方向”的工具——构建坐标系、求法线、算贴面流向、转 90°、判左右全靠它；记住结果永远垂直于两个输入，且 A×B 与 B×A 反向。

（六）归一化

没有疑问，以下是AI拓展

拓展一：把“方向”和“强度”拆成两个参数（最实用）
核心认识：原始向量 = 方向 × 强度。

做法：先 Normalize 去掉长度，再乘一个 ScalarParameter 当强度。
好处：风向、光照方向、扰动方向都能单独调，改强度时方向不会跟着歪。
例：(13,0,0) 先归一化成 (1,0,0)，再乘风速参数 0～10——想改风速只动一个数，方向永远稳定。

拓展二：Dot／光照／反射前的必要步骤
Dot(A,B) = |A||B|cosθ——只有单位向量时，点积才是“纯夹角余弦”。不归一化，亮度会随向量长度乱变。

用法：法线、光照方向、视线方向、反射向量、半角向量，参与计算前全部过一遍 Normalize。
这就是你笔记里“Dot 前必须 Normalize”的本质：把长度因素剔除，只留角度。

拓展三：径向方向场（UV 里最常用）
Normalize(UV − (0.5,0.5)) = 从圆心指向外的单位方向。

用途：径向模糊方向、雷达扫描、圆形扩散波纹、径向拉伸、噪声沿径向拉丝——先拿到方向，再乘距离／时间控制强度。

拓展四：方向类效果的基础件
粒子／广告牌朝向、激光光束方向：位置差 Normalize 得方向；
样条、管状效果：相邻点差值归一化得当切线；
法线贴图：解码后的切线空间法线必须归一化，否则光照偏暗；
两张法线混合后要再归一化——BlendAngleCorrectedNormals 内部做的就是这件事。

工程注意
零向量不能归一化：UE 里用 SafeNormalize，零输入返回零向量，防 NaN／黑块；
只改长度不改方向：负向量归一化后方向不变（(−13,0,0) → (−1,0,0)）；
归一化后记得乘强度，否则“方向对了但力气没了”；
常量向量编译期会被优化掉，逐像素的动态向量才需要留意开销（开方运算）。

一句话总结：Normalize 把“任意长度向量”压成“纯方向”——先归一化定方向、再乘参数定强度，是所有方向类材质的基本功；Dot、光照、法线混合之前都必须先过它。

（七）顶点呼吸动画

提问：用别的节点替换掉乘法，会产生哪些效果

AI分析：核心链：VertexNormalWS [运算] Sine(Time) [× 幅度] → WPO

以法线 (0.5, 0.2, 0.8)、正弦 0.5 为例：

乘：→ (0.25, 0.1, 0.4)，同比例变暗，色相不变——像呼吸灯；
加：→ (1.0, 0.7, 1.3)，整体提亮，高光洗白；
减：→ (0, −0.3, 0.3)，整体压暗，负通道截黑。
高频运算（按使用频率）

Multiply（最常用）：N × 波 → 沿法线伸缩。sin 正负自动形成“进出”，呼吸、风吹、水面都靠它；调大小改后面的幅度系数。

Add：N ＋ 波 → 每个顶点加同一个向量＝整体平移（WPO 里是斜着滑）；更常见的用法是叠加多层波（波1＋波2），让运动不机械。

Subtract：N − 波 → 与 Add 反向的偏移；常用来做反相／相位差（两列波相减出驻波）、让顶点往回“吸”。

Lerp：在两种形变之间混合 → 风的强弱、呼吸的开关，运行时可用参数控制。

乘遮罩（顶点色／UV 高度）：控制“哪里动”——根部不动、顶部摆，和上面任一运算叠加使用。
（Sin ↔ Cos 只差 90° 相位，用于错峰或椭圆轨迹，属于波形选择，不算合并运算。）

WPO 提醒：只动画面不动碰撞；幅度过大要调 Bounds Scale；沿法线偏移会裂 UV 接缝。

一句话总结：Multiply 定“伸缩”，Add／Subtract 定“偏移与反向”，Lerp 定“过渡”，遮罩定“范围”——顶点动画九成组合都在这一句里。

以下是AI拓展：

拓展一：风吹植被（行业里最常见的用法）

公式：Sin(Time × 风速 + WorldPosition.Z × 频率) × 幅度 × VertexNormalWS → WPO

相位差是关键：用高度（Z）参与正弦，越高相位越靠后，摆动自然有层次；
权重：用 UV.Y 或顶点色 R 当遮罩——根部 0（不动）、顶部 1（全摆），植物才不像整根在扭；
想要更自然，把 Sine 换成 Noise（噪声），纯 Sine 太机械。

拓展二：波传播（Time 管时间，坐标管空间）

Sin(Time × 速度 − WorldPosition.X × 频率) × 幅度 × 法线 → WPO

加号／减号决定波往哪个方向走，频率决定波长；
例：速度 2、频率 0.5 → 每米相位差 0.5 弧度，波从一侧推向另一侧；
用途：水面起伏、旗帜、传送带、能量护盾的波纹。
记住一句：Time 给时间相位，坐标给空间相位，两者相加＝波在跑。
拓展三：局部控制（遮罩权重）
把权重乘进 WPO：形变量 × 权重。权重可以来自顶点色、UV 高度、距离、遮罩贴图。

只有顶部动 → 植物、头发；
只有边缘动 → 布料边缘、旗帜；
只有局部动 → 机械部件伸缩、角色肌肉；
权重从 0 到 1 渐变，变形才不生硬。

拓展四：多频叠加做“活物感”

两个不同频率的 Sine 相加 → 不规则脉动（心跳、果冻、史莱姆）；
Sine ＋ Noise → 抖动／痉挛，适合怪物、故障感；
两个方向不同相位 → 椭圆／8 字运动（第十四课的正余弦组合，接到 WPO 就是轨迹）。
工程注意（比公式更重要）
WPO 只改渲染位置，不改碰撞——模型看着在动，实际碰撞体不动；
可能超出包围盒：位移太大时视锥剔除会误判，物体会突然消失——调大该组件的 Bounds Scale；
不更新法线：大幅度变形时光照会显得平、假，阴影和距离场也可能不跟随；
幅度单位是厘米：先用 5～10 试，50 已经开始穿模；
沿法线偏移会裂 UV 接缝（已知坑）；
静态网格组件要确认 Evaluate World Position Offset 是勾选状态。

一句话总结：WPO 顶点动画＝方向 × 幅度 × 相位——方向用法线，幅度用参数，相位用 Time＋空间坐标；改公式就能从呼吸变风吹、从脉动变波传播，但它只动画面不动碰撞，还要照顾好包围盒和法线。

（八）像素深度

问：如何调节A和B之间的比例

AI答：alpha接参数直接调节，但是二者有区别
<img width="1267" height="620" alt="image" src="https://github.com/user-attachments/assets/2cc86a28-d518-4f43-a56c-e12352c7c9b2" />
一、值的粒度不同（核心区别）
ScalarParameter：整个材质只有一个数，所有像素共用同一个 Alpha。
→ 结果：整个球／整块面均匀混色，只有一个颜色，没有空间变化。

PixelDepth 链：每个像素单独算——该像素到相机的深度 ÷ 2048 → Power → Saturate，近处和远处的 Alpha 不一样。
→ 结果：空间渐变——近处红、远处绿，或者反过来，模型表面出现距离分层。

二、是否跟随相机变化
ScalarParameter：不跟随。相机怎么动，颜色比例都不变，稳定、可控；
PixelDepth：跟随。相机一移动，远近关系变了，渐变位置跟着变；同一物体换个角度看，颜色分布也不同。
三、调节方式不同
ScalarParameter：在材质实例里直接拖 0～1，调的是“比例”本身；运行时蓝图也能改；
PixelDepth：调的是距离参数——分母（多远变色）、Exp（曲线形状）、乘加偏置；不能直接“拖比例”。
四、适用场景
接 ScalarParameter：

整体配色、两套外观按比例混合（新／旧、亮／暗、选中／未选中）；
材质实例批量管理，每个资产不同比例；
需要蓝图／Sequencer 运行时控制（渐变、过渡、呼吸）；
想要结果稳定、可预期，不随相机乱变。
接 PixelDepth：

距离雾、空气透视、远近颜色分层；
大场景里“近处清晰、远处淡化”；
需要随相机自动变化的效果（走近变清晰、走远变模糊）。

（九）场景深度

问：为什么不引入power节点

AI答：power是把线性渐变掰成曲线的工具，第八课像素深度用了是为柔化近处过渡，第九课场景深度不用是因为线性够用

拓展一：深度雾／空气透视（最常用）
后期处理里做“近处清晰、远处发灰”：

Saturate((SceneDepth − 起点) / (终点 − 起点)) → Lerp(原画面色, 雾色, 结果)

起点、终点控制雾从哪开始、到哪铺满；
想要自然衰减：1 − exp(−密度 × SceneDepth)；
这是大场景“空气透视”的最低成本做法，比体积雾便宜得多。

拓展二：软相交／DepthFade（水、玻璃、粒子）
核心公式：SceneDepth − PixelDepth ＝ 这个面到背后场景的厚度／距离。

Saturate((SceneDepth − PixelDepth) / 淡出距离) → 当透明物体靠近背后几何体时，差值变小 → 自动变透明，接缝不再出现硬边。

用途：水面与岸边、玻璃与窗框、粒子与地面、烟与墙——所有“透明物体插进实体”的场合。
不想手搓可以直接用内置 DepthFade 节点，本质就是这条减法。

拓展三：深度描边（边缘检测）
对 SceneDepth 做多点采样（上下左右各偏移几个像素），相邻深度差超过阈值就输出描边色：

用途：卡通渲染描边、建筑轮廓线、深度断层高亮。
优点：只描“前后关系”的边，不会把贴图细节也描出来。

拓展四：距离淡出（远景消失）
1 − Saturate((SceneDepth − 起点) / 范围) → 乘进不透明度：

远处的物体逐渐透明消失，不会“啪”一下被剔除——LOD 切换、远景资产收尾的常规做法。

拓展五：深度分层／扫描线（科幻、雷达）
frac(SceneDepth × 频率 − Time × 速度) → 沿深度方向滚动的亮带：

用途：雷达扫描、声呐、X 光效果、科幻界面、地形等高线式的艺术化染色。
配合 SmoothStep 可以控制亮带的宽度和软硬。

工程注意
只有半透明／后期处理材质能读 SceneDepth（刚踩过的坑）；
半透明里读的是“背后场景”的深度，PixelDepth 才是当前面自己的深度——两者相减才有意义；
后期处理的 UV 是屏幕空间，别当模型 UV 用；
远距离深度精度有限，容易出条带（banding），加一点噪声／抖动可缓解；
后期雾别叠太猛，会和体积雾、曝光互相打架。
一句话总结：SceneDepth 的用法就两类——看深度做分层（雾、淡出、扫描线、描边），算深度差做相交（DepthFade、水面、粒子）；前者管“远近”，后者管“厚薄”。

（十）菲涅尔
